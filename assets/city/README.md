# City assets (Kenney City Kit – Roads)

Source: https://kenney.nl / OpenGameArt CC0

Included for TemuDriver3DS:
- `road-straight.obj` – main road tile
- Mesh loader supports Kenney vertex-color OBJ format

**Note:** This pack is roads only (no houses). Buildings can be added later from Kenney City Kit Commercial or Quaternius packs as OBJ into this folder.

RomFS path: `romfs:/city/`
